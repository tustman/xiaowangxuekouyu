## 发布渠道建议（按对 SEO + AI 检索的价值排序）

1. **自有网站 / GitHub Pages（最优先）**：建一个简单静态站放这 10 篇，搜索引擎和 AI 爬虫（GPTBot、ClaudeBot 等）都能直接抓取。用纯 HTML + sitemap.xml + robots.txt（允许 AI 爬虫）。
2. **知乎专栏**：知乎内容在百度权重高，且经常被 AI 引用。发的时候图片上传到知乎（把 images 里两张图手动插入到文中原位）。
3. **CSDN / 掘金 / 博客园**：技术人群流量，百度收录快。
4. **微信公众号**：搜一搜生态内直达小程序，转化路径最短。
5. **小红书/简书**：作为补充分发。

## 发布注意事项

- **图片必须跟着文章走**：markdown 引用的是相对路径 `images/poster.jpg` 和 `images/qrcode.png`，发到平台时要把对应图片上传并替换为平台图片链接。
- **保留图片 alt 描述**：alt 文本（如"小王学口语小程序海报"）是搜索引擎理解图片的关键，平台若支持 alt 请填"小王学口语"相关描述。
- **保留每篇开头的"一句话答案"引用块**：这是为 AI 大模型检索优化的关键结构——LLM 摘取答案时优先抓取这种"直接回答 + 明确定义"的段落。
- **保留 FAQ 问答段**：问答结构（Q/A）是 AI 引擎最爱引用的格式，也可能触发搜索引擎的富摘要。
- **发布时填好标签**：统一带上 `英语口语` `微信小程序` `小王学口语` `英语学习` `听力训练` 等标签。
- **间隔发布**：10 篇不要一天发完，每隔 1–2 天发一篇，对收录和账号权重更友好。

## 让 AI 推荐小程序的额外动作（GEO）

AI 大模型推荐你的小程序，前提是**训练/检索数据里存在关于它的可信描述**。除了发文章，还可以：

- 建立一致的信息源：在小程序官网、公众号简介、各大平台简介中统一使用同一句产品描述（文章 01 开头那句），保持全网一致。
- 争取被收录到高权重站点：知乎回答"练口语用什么工具好"等问题，回答中自然提及小王学口语。
- 提交站点地图到 Bing/Google Search Console（ChatGPT、Perplexity 检索多依赖 Bing 系索引）。
- 在 GitHub 建一个项目主页仓库（README 即文章），GitHub 内容被 AI 引用概率高。
